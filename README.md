# Grape

## 機能一覧

| 機能名               | 説明                                                                                               |
| :------------------- | :------------------------------------------------------------------------------------------------- |
| フィルター機能       | 動画一覧検索で使用するフィルターを保存する                                                         |
| クイズ機能           | 女優の顔写真から生えているか生えていないかのクイズを出題する機能                                   |
| フィードバック機能   | ユーザーからの要望をGoogleFormで送信する                                                           |
| ギャラリー機能       | 動画一覧ページで作品上に3秒以上カーソルがあったた場合に、画像の一覧を表示する                      |
| 動画作品一括操作機能 | 動画一覧ページでチェックボックスをチェックした作品のサンプル動画を一括再生とバスケットへの追加する |
| 新作通知機能         | フィルターの条件に合致した新作を通知する機能                                                       |

## 機能詳細

### フィルター機能

- [x] AVに対応している
- [x] 素人に対応している
- [x] アニメに対応している
- [x] 機能をオフにできる

#### フィルター保存機能

- [x] フィルターを追加できる
- [x] フィルターをコピーして追加できる
- [x] フィルターを編集できる
- [x] フィルターを編集時にリセットできる
- [x] フィルターを削除できる
- [ ] フィルターの順番を並べ替えできる
- [ ] 詳細なフィルターを保存できる
  - ブラウザブックマークとの比較が必要

#### フィルター適用機能

- [x] ボタンを押した時に、URLを変更する
- [x] ボタンにホバーした時に、フィルターの説明を表示できる

### 動画作品一括操作機能

- [ ] 一覧画面から作品を複数選択して、サンプル動画を再生できる
- [ ] サンプル動画の一覧から指定した作品をバスケットに追加できる
- [ ] サンプル動画の一覧から指定した作品をお気に入りに追加できる
  - 一覧画面からお気に入り追加ができないため、調査が必要

### クイズ機能

- [ ] 女優のアンダーヘアが生えているか生えていないかのクイズに回答ができる
- [ ] 女優のおすすめ作品の一覧を確認できる

### ギャラリー機能

- [ ] 作品にホバーした時に、作品の画像の一覧を見ることができる
- [ ] 作品のギャラリーを一括でダウンロードできる
- [ ] 作品のギャラリーを押すと、詳細ページに遷移できる

### フィードバック機能

- [ ] Googleフォームからフィードバックを送信できる
