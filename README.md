# Grape

## 機能一覧

| 機能名               | 説明                                                                                               |
| :------------------- | :------------------------------------------------------------------------------------------------- |
| フィルター保存機能   | 動画一覧検索で使用するフィルターを保存する                                                         |
| クイズ機能           | 女優の顔写真から生えているか生えていないかのクイズを出題する機能                                   |
| フィードバック機能   | ユーザーからの要望をGoogleFormで送信する                                                           |
| ギャラリー機能       | 動画一覧ページで作品上に3秒以上カーソルがあったた場合に、画像の一覧を表示する                      |
| 動画作品一括操作機能 | 動画一覧ページでチェックボックスをチェックした作品のサンプル動画を一括再生とバスケットへの追加する |
| 新作通知機能         | フィルターの条件に合致した新作を通知する機能                                                       |

## 機能詳細

### フィルター保存機能

- [x] AVに対応している
- [x] 素人に対応している
- [x] アニメに対応している
- [x] フィルターを追加できる
- [x] フィルターを保存できる
- [x] フィルターをコピーして追加できる
- [x] フィルターを編集できる
- [x] フィルターを編集時にリセットできる
- [x] フィルターを削除できる
- [ ] フィルターの順番を並べ替えできる
- [ ] ボタンにホバーしたとき、フィルターの説明を表示できる
- [x] フィルターを商品一覧ページに表示できる
